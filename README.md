# NVT Data Analysis Task 7 - Business Intelligence Dashboard

## Project
Business Intelligence Dashboard Using Power BI

This project is prepared for Novexa Technologies Data Analysis Task 7.

## Dataset
The supplied `train.csv` contains 9,800 rows and 18 original columns.

The dataset contains sales/order/customer/product information. It does not contain Profit or Quantity, so the dashboard does not invent those metrics.

## Tools
- Microsoft Power BI Desktop
- Power Query
- DAX
- CSV
- GitHub

## Dashboard KPIs
- Total Sales: $2,261,536.78
- Total Orders: 4,922
- Total Customers: 793
- Average Order Value: $459.48

## Visualizations
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Sales by Segment
- Top Sub-Categories
- Optional geographic analysis by State

## Slicers
- Order Year
- Region
- Category
- Segment
- Ship Mode

## Data Cleaning
- Converted Order Date and Ship Date to dates.
- Checked missing values.
- Identified 11 missing Postal Code values.
- Added Year, Month and Year-Month helper fields.
- Added Shipping Days.
- Prepared a Power BI-ready cleaned CSV.

## Key Insights
- Highest-sales category: **Technology**
- Highest-sales region: **West**
- Highest-sales segment: **Consumer**
- Highest-sales month: **NaT**
- Highest-sales sub-category: **Phones**
